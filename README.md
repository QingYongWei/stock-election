# 创作罗盘（暂名）0.3 · 多领域内容创作工具

**面向内容创作者的多领域内容生产工具。用户可选择不同方向，建立独立工作空间，按自己的目标组织选题、创作、审核与发布。**

先看具体方向和作品，再选择愿意尝试的方案。选择后自动建立方向卡，生成公众号文章、小红书独立文案及四张图卡，最后由你核验、审核和发布。

当前版本可由不同用户独立安装在本地使用；暂未提供公网多租户账号系统。主品牌名称、商标、域名仍待确定。

## 1. 启动或升级

需要Python 3.11+、Pillow和中文字体。Windows启动器兼容Windows PowerShell 5.1和PowerShell 7；脚本保持纯ASCII，避免系统代码页引起解析错误。首次安装：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-agent.txt
.\start.ps1
```

也可双击[启动工作台](<启动工作台.cmd>)。默认打开 **http://127.0.0.1:8765/**。

**旧服务若还在运行，先等正在生成的任务完成，再在你原来的启动窗口按Ctrl+C，启动新版并强制刷新浏览器。** Python后端不会随源文件自动热更新；不要只刷新新前端却继续运行旧后端。重复启动不会抢占已用端口，也不会擅自关闭其他进程。

升级时保留原数据目录。默认位置是项目根目录下的`data/stock_agent`；从新的版本目录启动时，请复制保留数据，或设置 `STOCK_AGENT_DATA` 指向原目录。必须先停旧服务；不要让不同端口的两个进程共享同一个数据目录。

已有0.2数据库首次迁移前会创建 `agent.pre-platform-v030.backup`，原配置、历史任务及图片不删除；旧记录归入财经空间。备份和运行数据库都可能含Key，请妥善保护。

新安装不会强制创建财经空间；已有财经配置会自动迁移为原品牌工作空间。

## 2. 从方向卡开始，不先填定位问卷

首页和「找方向」提供六类编辑预置方案：财经、职场、科技、生活、书影音、学习。

- 卡片展示为谁写、实际做什么、具体标题与样稿开头。
- 「先看完整样稿」仅预览，不创建空间、不花模型费用、不当作真实任务。
- 「选这个，创建空间」才会保存工作空间，并形成初始方向卡。
- 没感觉可以换批、按领域筛选或恢复不感兴趣的方向。

预置样稿不是实时市场分析或个性化赛道判断，不承诺涨粉、收入或适合所有用户。

## 3. 按方向组织内容生产

所有领域使用同一条操作路径：选择方向 → 创建工作空间 → 生成内容 → 人工审核 → 导出与发布。空间名称、读者和表达风格以所选方案作为初始值，用户可按自己的用途调整；产品不绑定某个使用者、内容账号或经营目标。

财经、职场、科技、生活、书影音与学习是可选方向，各工作空间在首页统一展示。已有空间可以直接进入，无须重复定位。

财经生产沿用真实行情、公告线索、可用历史数据与可读公告摘录研究。发布前仍须由用户核验来源、事实与适用边界；资料不足时模型不能补造。观察代码、表达偏好、计划与DSA收进高级设置，不作为新手浏览方向的前置条件。

没有模型时，财经仍可采集资料，但明确是**资料包，非可发布AI成稿**，不能批准或复制成发布正文。

## 4. 模型服务商：自己注册、充值、使用自己的Key

在「服务商」填写连接名称、OpenAI兼容API Base、账户实际可用的模型ID与Key，点击 **「保存并用于创作」** 即可。默认由同一个模型完成选题和写作，无须再配置任务分配。

已有连接无需重填Key，点击卡片上的 **「用于创作」** 即可启用；页面顶部显示当前生效的创作模型。若只是保存备用连接，选择「仅保存连接」，不会切换当前模型。只有希望两个步骤使用不同模型时，才需要展开 **「高级：分别设置选题和写作模型（可选）」**。模型选择由本机全部工作空间共用，切换影响后续新任务。

保存或启用接口本身不请求上游模型；手动生成、连接测试和已启用的自动计划可能产生服务商费用。保存成功不等于连接已测试，也不保证实际成稿质量。

预设提供DeepSeek、阿里云百炼、硅基流动与自定义兼容接口。预设不保证特定模型存在或账号有权限，模型ID请以服务商控制台为准。

- 自行在服务商官网注册与充值，费用直接由服务商收取。
- 本项目不设平台钱包、充值订单、代扣模型费用或统一算力账单。
- 推广入口可显式配置并标注；默认没有虚构的合作或返佣承诺。
- 保存Key只代表已保存，不代表连通。连接测试会发出一次最小真实请求，可能收费；每篇生产通常有两次模型请求。
- **Key不要发到聊天里。** 接口不回显Key；编辑时留空保留，显式清除才删除。删除或解绑后不会偷偷复活旧版Key。
- 自建免鉴权服务若要求兼容客户端传入Key，请按该服务的要求使用占位值并自行验证。

首版只支持OpenAI兼容聊天接口，不承诺厂商原生协议、流式接口或所有模型均适配。

## 5. 工作空间、稿件和反馈分别保存

每个空间独立保存品牌、读者、目标、风格、素材、自动计划、稿件归属和自报反馈。模型连接与默认任务分配属于本机用户共用设置，不在各空间复制Key。

切换空间不会混入别的空间任务。生成结果绑定原空间；按意见重生成仍归原空间，不随当前页面切换。未保存改稿和配置会提示处理后再离开。

反馈无需收益、阅读量或粉丝数，可以留空。不读取外部平台分析数据。

## 6. 非财经首版能力与边界

职场、科技、生活、书影音、学习方向支持真实模型的两阶段选题与创作，但首版采用**常青解释、通用知识和原创虚构例子**，不是多领域实时联网研究。

- 不调用股票行情，不把财经免责声明套给其他领域。
- 可选用户素材只作待核资料，不自动抓取URL、不当作已核实外证。
- B1代表创作简报，不是外部事实证据。
- 正文保留AI辅助、无实时检索、虚构非亲历、材料需人工核验及领域边界；删除披露会阻止批准。
- 来源、结构、长度检查不等于事实、版权或合规审核。

未配置完整模型时不会拿预置样稿冒充生产结果。模型请求或校验失败会保留失败记录，不降级伪装成功。

## 7. 两个平台怎么发

### 公众号

复制标题 → 复制排版正文（HTML及纯文本）→ 到公众号后台粘贴 → 补封面并预览 → 人工发布。

不支持剪贴板权限时可打开安全排版预览手选复制。公众号可能过滤样式，以平台最终预览为准。复制不等于发布。

### 小红书

下载整组图片ZIP → 按01至04上传 → 复制独立标题和正文 → 平台预览 → 人工发布。

图片1080×1440，小红书标题最多20字、正文最多1000字。文章、文案和图卡分别核对；**改文章不会自动重写图卡**。

### 修改和归档

高级编辑保存后撤销原批准；核验全部文字与图片，勾选复核后批准。批准指纹绑定正文和PNG，修改后不能沿用旧批准。用户在外部平台发布后填写URL归档，这只是手动记录，不是自动发布或平台认证的发布成功证明。

## 8. 自动计划与DSA

每空间可保存北京时间计划；默认关闭。财经工作日日报和指定周报沿用原规则，非财经按自己的日计划与周报日运行。任务串行执行，按空间和日期防重复；同日已认领的失败任务不会无限重试，需手动重新生成。

服务必须持续运行；关机、休眠或停进程会影响计划。工作日并不等于完整交易所节假日日历。

DSA仅财经高级可选：可导入原生Markdown报告或显式启用单次运行。检查项目`main.py`、Python解释器和reports目录对应关系。只接受本次manifest绑定的新报告，未核验结论不能当公开事实。安装流程见[获取脚本](<tools/fetch_dsa.py>)、[安装脚本](<tools/setup_dsa.ps1>)；DSA及其依赖不打入主程序源码包。

## 9. 安全与安装边界

- 本机SQLite存储Key，**不是加密凭证库**。保护电脑账户、数据目录和备份，不将数据库打包分发。
- 不直接暴露公网端口；无多租户身份和公网认证系统。
- 每个客户部署独立实例、独立数据目录。可通过 `STOCK_AGENT_DATA` 与启动参数 `-Port` 区分，但同一数据目录只运行一个服务。
- Linux/macOS用虚拟环境Python运行 `-m stock_agent.server --port 8765`；中文字体缺失时设置 `STOCK_AGENT_FONT`。
- 图片太长会报错，不静默截断结论。AI失败先检查模型ID、Key、额度、API兼容性和网络。
