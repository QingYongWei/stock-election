## 实际检查结果补充

- 连接三种结果、demo-Key限制、非法URL协议拦截、用户HTML输入仅按文字显示，均已检查。
- 选题/写作可分配不同已连接服务；删除默认服务会撤销相应默认并重新阻止生成，重新分配后恢复。
- 公众号HTML+纯文本载荷及剪贴板拒绝后的手工复制对话已检查。未改动操作系统剪贴板。
- 演示PNG生成后读取文件头验证为1080×1440；内容JSON带演示声明且不包含Key。下载验证使用页面拦截器，未写入操作系统下载目录。
- 文章、图卡和小红书独立标题/正文改稿可保存；未保存拦截复制/下载/批准，保存后回到待审核。
- 模拟发布只记录example.invalid地址，未访问该地址。浏览器资源记录中没有HTTP(S)请求。
- 390px下四个页面及已生成内容均无横向溢出；弹窗宽度不超过390px，Escape可关闭。
- 页面无console error/warn；JavaScript语法检查通过；无外部字体、脚本、请求和本地存储调用。
- 正式应用9个源文件的SHA256与开始时一致。没有修改正式数据、配置或服务，没有启动测试服务器。

这些检查是原型交互检查，不是正式应用的功能回归或真实模型质量验收。
