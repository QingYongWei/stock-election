# P0.5 · 通用内容平台与个人财经工作空间

## 本轮结论

**平台可以服务多个内容方向；股票/财经是你个人想尝试的方向，不是整个平台的范围。**

因此，本轮独立原型采用：

- 平台暂名：**创作罗盘**。仅作评审占位，名称、商标与域名均未确定或核验。
- 你的个人财经工作空间：**盘后工坊**。已选财经方向，可直接进入，不用每次重新定位。
- 其他工作空间：由用户从具体方向和作品中选择后开启，各自保留偏好、稿件与反馈。

本轮仍只迭代HTML/CSS/JS评审原型，不是正式软件升级，不接真实AI、支付或发布接口。正式应用和P0.4原型均不覆盖。

[打开交互原型](<index.html>)。无需服务器，下载后请整包解压，保留同目录的脚本和样式。

## 两条评审路径

### 路径A：你已有财经方向

1. 平台首页点击「进入盘后工坊」。
2. 直接看到自己的财经工作空间、已选方向与最近稿件。
3. 点击「继续财经试做」，展开公众号文章、小红书独立文案和四张图卡。
4. 体验改稿、审核、复制、下载和模拟手动发布记录。

不会再问你“是否开始做股票内容”“目标读者是谁”“怎么设计账号定位”。

### 路径B：用户还不知道做什么

1. 点击「看推荐方向」。
2. 直接看方向卡：服务谁、实际做什么、具体标题、样稿开头和图卡。
3. 「先看样稿」可以打开完整预置样稿，不会创建空间或改变个人偏好。
4. 「选这个试试」才会开启对应工作空间，并自动填好初始方向卡。
5. 默认只试1篇，可自行选少量篇数，不根据空闲时间推断能力。

**没有前置定位问卷。** 用户做的是“更想看、愿意试哪一种”的选择，不是替系统做运营设计。

## 多样化展示范围

本轮有6类方向、13份对应预置内容：

| 方向 | 示例作品 |
| --- | --- |
| 财经问题讲清楚 | 指数反弹为什么不等于大家都涨；热度到订单；收入与回款 |
| 职场沟通 | 向同事提需求；把周报从流水账改为进展与阻碍 |
| 科技工具解释 | AI工具的能力边界；先按任务选择工具 |
| 生活决策 | 收纳盒之前先确认物品位置；购买前检查使用场景 |
| 书影音观察 | 从虚构剧情观察表达；区分作品事实与个人感受 |
| 学习方法 | 为笔记建立使用入口；用小任务检验理解 |

方向来自编辑精选示例，不是实时市场分析或精准个性化推荐。不会据此承诺用户适合某一赛道、能涨粉或赚钱。

## 选择交互

- 默认一批3个方向，可换批、按领域筛选或查看全部。
- 可以标记不感兴趣；全部排除后有恢复入口，不会困在空状态。
- 样稿预览不等于选定方向。
- 「先只浏览推荐方向」仅切换当前演示账号的浏览视图，不是切换真实账号，也不会清掉已有盘后工坊。
- 本原型为本次评审预置个人财经空间，不代表正式产品会给所有新用户默认设置财经账号。

## 工作空间之间的边界

每个空间分别保存本会话内的名称、读者/风格/范围、试做篇数、反馈与最近稿件。

- 财经与职场等空间的稿件和反馈不串用。
- 切换前会保留当前空间；有未保存改稿或样稿仍在展开时，会阻止切换。
- 模型服务商与任务分配是平台共用设置，不复制Key到每个空间。
- 会话刷新后演示状态会重置，不代表已实现正式用户账户、云端存储或多租户权限。

## 不把财经模板套给所有领域

财经空间强调来源、事实与观点、不荐股及风险边界；非财经样稿使用对应规则：

- 职场：隐私、权限与情境差异。
- 科技：版本、实测和推断分清。
- 生活：场景适用，不绝对化或提供医疗判断。
- 文化：原创、版权、剧透及事实/感受区分。
- 学习：个人经验不能保证成绩。

职场等空间的正文、复制内容、图卡和导出包不再带“不是投资分析”“盘后工坊”等财经模板字样。

## 商业模式保持不变

工具内置服务商入口与接入预设；用户向服务商自行注册、充值并使用自己的Key。本项目只提供接入与推广入口，后续合作收益按服务商协议确定。

没有平台钱包、模型代充值、代扣费用或统一算力计费。本原型的官网跳转、连接测试与生成仍为模拟。

## 请重点评审

1. 是否能一眼分清“通用平台”和“我的盘后工坊”？
2. 你的财经路径是否足够直接，不需要重新做定位题？
3. 不知道方向的用户，能否从具体作品中做选择，而不必先设计方案？
4. 多领域样稿是否体现了真实差别，而不是把股票文章换标题？
5. 工作空间切换、稿件与反馈归属是否符合直觉？
6. 是否认可这种平台结构，再决定品牌名称和正式研发范围？

本次展示的是交互与内容结构，不是跨领域真实AI能力已上线。真实选题研究、数据源、领域审核策略、模型接入和正式存储，均须评审后另行确定研发。
