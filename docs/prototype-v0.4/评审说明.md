# 创作罗盘（暂名） P0.4 · 不知道做什么，也能开始

本轮仍是独立可交互原型，不是正式应用升级。P0.3原型与正式应用均保留，不覆盖、不接真实模型、充值或平台发布。

入口：[打开新版交互原型](<index.html>)。无需启动服务器；下载时请整包解压，保留HTML、CSS和两个JS文件的相对位置。

## 针对本次反馈改了什么

旧流程把“目标读者、内容目标、表达风格、观察对象”等定位决策交给了用户，这恰恰是很多新手无法开始的原因。

新版将流程改为：

**不知道做什么 → 最多3个可跳过的问题 → 推荐一个待验证方向 → 自动生成账号方向卡 → 小规模试做 → 看一篇样稿 → 反馈后调整。**

专业配置表不再是前置门槛，而是系统方案生成后的高级微调。

## 建议首先测试这条“什么都不知道”路径

1. 首页点「我还不知道做什么 / 帮我探索方向」。
2. 点「都不确定，直接看看建议」。
3. 不必阅读全部备选，直接点「先按主推方案试做」。
4. 查看已经生成的账号方向卡与一篇小试做。
5. 直接点页首「直接看第一篇演示样稿」，或计划卡里的「先看演示样稿」。**不用先读完全部方向资料，不用填任何定位字段，也不用连接模型服务商**。
6. 在两平台内容页看文章、图卡和独立文案；想修改或体验审核，继续操作即可。
7. 回试做计划，点「记录 / 回看反馈」；即使没发布、没有阅读量，也可以跳过并获得后续选择。

「先看演示样稿」是打开预置离线样稿，不是未付费使用真实AI。真实模型个性化规划与生成不在本轮原型实现范围。

## 新的信息架构

| 页面 | 用户需要做的事 |
| --- | --- |
| 从这里开始 | 选择从零探索，或说明已有账号/方向 |
| 探索内容方向 | 回答现实问题，或全部跳过；查看系统主推及备选 |
| 我的试做计划 | 确认一个暂时的起点，只试1—3篇，不默认日更 |
| 内容预览与发布 | 读懂样稿在验证什么，体验改稿、复制、图卡下载与人工审核 |
| 模型服务商 | 看过样稿后再决定是否接入自己的模型服务 |
| 方向与高级设置 | 查看自动生成的方向卡，按需展开底层字段微调 |
| 试做反馈 | 从计划中进入；简单自报感受，不要求平台数据或收益指标 |

## 三个问题，而不是五道运营作业

- 现在是否已经开始做股票内容？
- 比较愿意试资料审核图文、分享学习经历、出镜，还是都不知道？
- 一次愿意留约10分钟、30分钟，还是时间不定？

所有问题都可跳过，可以返回修改，也可以离开后在本会话继续。不会把“愿意出镜”“发过几篇”当成已具备金融专业能力。

## 推荐方案提供什么

工具面向所有用户开放。此历史原型仅以股票/财经作为流程演示领域，工作空间示例名称为「财经笔记」，不代表用户实际已选方向或所有用户默认配置。示例包含：

1. 财经现象讲清楚。
2. 公告阅读练习。
3. 行业小观察。

每个方向提供读者价值、每次实际要做的工作、材料/能力门槛、具体选题、主要风险和可能商业化路径。商业化只说明前提和可能性，不推算收入、粉丝或收益。

默认主推只是预置规则与待验证假设，不是精准画像，也不代表“这就是你最适合的赛道”。方向可以重选，旧任务历史不会被清除。

## 不是先承诺长期日更

- 时间不定：默认先看1篇样稿，再决定是否继续。
- 约10分钟：建议低频2篇，明确资料核验可能超时。
- 约30分钟：最多3篇，仍不保证能在30分钟完成。

试做计划不是实际定时任务，不会自动发布。每篇会说明“这篇在验证什么”，不只给一个标题列表。

## 反馈不是数据考核

只需说明是否发布、读起来/准备起来难不难、收到什么问题或卡在哪里，也可以全部跳过。

反馈仅为自报，不读取平台阅读量、粉丝或真实发布状态。系统可以建议继续一篇、降低频率或换方向，但不会自动替用户切换方向或创建计划。

## 已有账号的人怎么用

首页仍保留「我已有账号或方向」。主动选择后，可展开原来的高级字段，自行微调；不会强迫已有经验者重走新手探索。

## 保留的商业边界

服务商注册、充值仍在服务商官网完成，资金不经过本项目。工具只内置接入与推广入口；没有平台钱包、充值订单或代扣费用。原型中的服务商、连接和外链跳转仍全部是模拟。

## 本轮请重点评审

1. 不知道目标、读者和风格时，是否真的能顺着主入口走下去？
2. 问题是否容易回答？“全部跳过”是否能直接看到价值？
3. 方向方案是否说清了每天实际要做什么，而不是换一种方式让用户自己做运营规划？
4. 自动生成的方向卡和少量试做，是否比一上来填写配置更容易接受？
5. 没发作品、没有反馈时，是否还能得到下一步，而不是被数据指标卡住？
6. 哪些地方仍然让你觉得“我不知道怎么选、怎么开始”？

评审后再决定是否研发真实AI规划、服务商接入和正式产品交互。本原型的样稿与推荐均不作为实际AI质量或商业成果证明。
