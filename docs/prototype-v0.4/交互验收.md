# P0.4 原型交互验收

日期：2026-11-17。本记录仅针对独立评审原型，不代表真实AI、供应商、支付或发布接口已研发。

## 已实际检查的路径

| 场景 | 结果 |
| --- | --- |
| 初次进入 | 主入口是不知道做什么，不先索要账号定位或模型Key |
| 全部不确定 | 一键跳过三个问题，展示3个方向并自动主推一个，无专业字段输入 |
| 确认主推 | 自动形成品牌/读者/价值/风格/观察范围，进入试做计划 |
| 默认轻量试做 | 时间不定为1篇；10分钟意愿为2篇；30分钟意愿最多3篇，均不承诺按时完成 |
| 不连服务看样稿 | 0个服务商也能打开预置两平台样稿，带本轮方向、试做问题及明确的演示标识 |
| 问答后推荐 | 已发过内容、愿做资料审核、约30分钟时，演示规则可主推公告练习，并保留能力局限提醒 |
| 重选方向 | 需要确认，清空本轮反馈、递增试做轮次、保留旧内容历史 |
| 没发布也能反馈 | 全部跳过仍可保存；提供继续、减频或换方向选项，不强制收入/粉丝/阅读量输入 |
| 高级表单后置 | 默认折叠；主动选择已有账号时展开，字段无required，不阻止开始 |
| 自有模型流程 | 无服务时引导接入；模拟接入后可回计划继续，Key不进入保存的服务对象 |
| 未保存改稿 | 尝试更换方向被阻止，回内容页仍能撤回未保存改稿，原任务未丢失 |
| 390px布局 | 首页、探索、计划、反馈、服务商、高级设置、内容页均无横向溢出 |
| 样稿入口可达 | 手机首屏可见“直接看第一篇演示样稿”，不用读完全部方向卡再开始 |
| 离线边界 | 浏览器资源检查为0个HTTP(S)请求；未调用真实模型、充值或平台发布 |

还检查了手机上从“全部不确定”到确认方向、页首直接看样稿的完整路径；最新样稿的中心论点与被选主题对应，非空字段默认值无需用户预先填写。

最后另开独立测试页复验了高级设置：自动化默认「暂不开启」、高级表单折叠、required字段为0、HTTP(S)请求为0；该页无console error/warn，复验后已关闭。所有本轮脚本都通过语法检查。

## 原型与正式应用隔离

- 原型只在本地HTML、CSS、JS中运行，没有启动服务端口。
- 正式应用源文件校验与本轮开始时一致；具体校验结果在打包时再次确认。
- P0.3原型保留供对照，新版独立放置，不覆盖正式工作台。
- 没有读取或改写正式客户数据库、配置或模型Key。
- 旧版公众号复制、演示PNG下载等交互保留，但本轮主要验收从零探索路径，不把旧版验收冒充新增的真实平台验收。

## 重要限制

1. 推荐是预置方向和简单规则，不是真实AI画像；样稿是离线预置，不是免费实际模型调用。
2. 方向仍限定为股票内容，不代表已经设计完成全领域自媒体赛道选择。
3. 反馈只是用户自报；未获取平台分析数据，也不保证流量、粉丝、收益或商业化结果。
4. 浏览器刷新/会话重置会清空演示状态；没有真实定时任务或自动发布。
5. 需要你评审后再决定是否研发真实AI规划、数据接入和正式产品交互。
